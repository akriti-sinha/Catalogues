# **uGMRT Radio Galaxy Catalogs**
This repository contains two radio galaxy catalogs derived from observations with the upgraded Giant Metrewave Radio Telescope (uGMRT).

# **1. The Boötes Field at 400 MHz**
This catalog contains 3782 radio sources identified in the Boötes field, observed with the uGMRT at 400 MHz. The data covers a sky area of approximately 6 square degrees, achieving a central minimum off-source rms noise of
35 μJy/beam. The full details of the survey and the catalog can be found here:

[Detailed study of the Boötes field using 300-500 MHz uGMRT observations: source properties and radio-infrared correlations](https://ui.adsabs.harvard.edu/abs/2023MNRAS.525.5311S/abstract)

# **2. The ELAIS N1 Field at 1250 MHz**
This catalog contains 1086 radio sources from the European Large-Area ISO Survey-North 1 (ELAIS N1) field, observed with the uGMRT at 1250 MHz. A central off-source RMS noise of ∼12 μJy/beam was reached. More information is available in the associated publication:

[Spectral study of faint radio sources in ELAIS N1 field](https://ui.adsabs.harvard.edu/abs/2023JApA...44...88S/abstract)
